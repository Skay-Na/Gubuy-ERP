# ERP 调试 CLI 实施方案

## 目标与范围

提供 Go 单文件程序 `erpctl`，通过现有 HTTP API 调试 ERP，通过 SSH 收集 Docker 日志。第一版不直接连接数据库、不执行业务草稿确认或部署。Agent 提问会保存会话、消息，现有 Agent 也可能学习记忆或生成待确认草稿；评测建议使用测试环境。

## 实施步骤

1. 新增管理员专用消息追踪 API：按消息 ID 查询，必须同时校验会话归属；返回消息及解析后的 trace/task/evidence，不改变普通消息序列化。
2. 实现 CLI：`doctor` 检查数据库支撑的系统状态及管理员 AI 配置接口；`agent ask` 创建或复用会话、提问并读取追踪；`agent trace` 查询已保存消息；`agent eval` 逐项检查完成状态及预期文本；`logs` 读取本地/远端容器日志。
3. 配置统一使用环境变量与命令参数：服务 URL、JWT、超时、SSH 主机。JWT 只从环境读取，程序不存储凭据。支持参数出现在问题文本之后。
4. 输出支持文本及 JSON；退出码 0 成功、1 操作失败、2 参数错误、3 诊断/回答/评测未通过。错误输出在 stderr；诊断及评测结果在 stdout。HTTP 禁止跨站重定向，限制响应大小；日志参数验证后才拼接远端固定命令。
5. 用 httptest 验证鉴权、请求路径、错误响应、超时和完整工作流；验证追踪归属；运行全量 Go 测试、vet、CLI race 测试及构建。记录无法验证的真实服务行为。

## 验收

CLI 无需数据库配置即可启动和显示帮助；无需管理员凭据可执行基础 doctor；ask 输出 session_id/message_id 与追踪；不完整回答返回非零；评测包含失败原因和完整结果；logs 参数不能注入 shell。

## 交付与上线

补齐使用文档和示例评测文件。构建产物在 bin/，不提交。追踪接口需要部署新版后端后才能在远端使用；本次只实现并验证，不主动部署或调用真实模型。

## 实施结果（2026-10-05）

已完成全部五个命令、消息追踪 API、使用文档和示例。CLI 流程/错误/参数/诊断/评测/race 测试通过；新接口在独立 `erp_cli_audit_test` 库通过管理员归属及员工/未登录拒绝测试；完整 controller 测试（含 integration 标签）通过。相关包 vet 及 CLI 构建通过。本地运行中的 ERP 服务基础 doctor 和 Docker logs 实测通过。

全量 `go test ./...` / `go vet ./...` 存在原有 scripts 多 main 冲突；全量测试还发现生成的 Swagger 与当前路由不一致。新接口已提供 Swagger 注释，生成文档需与现有缺失注释一并同步。初次默认 3306 数据库测试未连接成功，后改用现有 3308 测试容器的独立测试库完成 controller 验证。未部署后端、未测试真实模型或远端 SSH；ask/trace/eval 工作流通过 httptest 验证。

## 第二轮实施方案

1. `auth login/status/logout` 复用管理员密码登录；隐藏密码输入或显式 stdin；仅保存 JWT，按规范化服务 URL 独立存储，目录 0700/文件 0600、拒绝符号链接与宽松权限、原子写入；环境 token 优先，过期提示重新登录。状态检查同时验证服务器鉴权，注销仅删除本地凭据。
2. 评测增加 topic、metrics、periods，以及 business_report 证据中的数值断言（指标、期间和非负绝对误差）。配置错误在调用模型前拒绝，缺数据、格式错误、重复冲突均失败；保留原有文本断言。
3. 数据库会话增加 debug 标记，由服务端强制禁止记忆读取/写入与业务草稿创建；保存对话、上下文和追踪。CLI ask/eval 默认 debug，旧服务若未确认支持立即停止；复用会话必须匹配模式，普通 UI 默认不变。
4. 更新示例及文档；验证登录流程、地址隔离、凭据权限与过期、结构化断言、旧后端保护、调试记忆隔离及普通会话回归。使用独立测试库完成后端集成验证，不更新生产容器。

### 第二轮实施结果

已完成 auth login/status/logout、按 URL 隔离的受限本地 JWT 存储、隐藏终端密码输入及 stdin 登录、环境 token 优先与过期提示；原有 CLI 命令仍可用。评测新增主题/指标/期间/金额误差断言与逐项结果。会话 debug 字段由 AutoMigrate 添加；CLI 默认使用 debug 会话，后端隔离长期记忆读写并阻止草稿，保留消息与追踪，旧后端在发送问题前被拒绝。

已通过 CLI race 测试、相关包 vet、macOS/Linux ARM64 CLI 构建、后端构建、前端构建。隔离 MySQL 库中的调试记忆/权限/普通记忆回归测试通过；实际 CLI 与真实 Gin handler 联通测试跑通密码登录、凭据恢复、状态验证、调试提问、固定金额断言评测与注销，模型使用测试桩，不产生真实模型费用。生产容器未更新，下一次更新后可实测新增 debug 功能。
