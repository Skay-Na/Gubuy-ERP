## 二、生产同步做法（不搬运本地 balance_after）

- 全部 DML 用**业务键锚定**：`order_no` / `related_no` + 旧金额 + 品种 + `category='销售订单采购成本'` 守卫，不用裸 ID
- B 类已售明细按**订单号白名单**匹配，避免 `product_id + 旧值` 全量更新误伤红冲单
- 余额链按生产流水**全量重放**：
  ```sql
  SUM(CASE WHEN flow_type=1 THEN amount ELSE -amount END)
    OVER (PARTITION BY account_id ORDER BY created_at, id ROWS UNBOUNDED PRECEDING)
  ```
  期初 0 已验证（三账户 净额=余额）；`flow_type=1` 收入加、`2` 支出减，`amount` 恒为正
- 单事务执行 + `historical_cost_repairs` 20 条 + `operation_histories` 留痕
