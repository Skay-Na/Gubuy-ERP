# 2026-10-29 工资按「所属月」重新归属

## 为什么改

`financial_logs` 里 27 条历史工资流水的 `related_no` 是开销账导入时的 EXP 单号（`EXP20260215002` 这类）。
真实净利润接口 `monthlyPayrollTotal` → `payrollBelongsToWindow` 只认 `PAY-<YYYY-MM>` 前缀，
其余一律**回落按 `created_at` 归属**，于是店里「月初发上月工资」的习惯导致每月工资都晚记一个月：

- 3 月工资 7,741（4-02 发）被记进 4 月 → 3 月净利虚高 7,741、4 月偏低
- 董庆庆 8 月那 550（8-21 发）在员工工资条里被算成 7 月

工资条接口 `payrollSalaryMonth` 有三级兜底（PAY 前缀 → 备注 `<YYYY-MM>工资/薪资/提成` 标记 → 实付月上一个月），
但真实净利润只走第一级，两处口径不一致。

## 改了什么

27 条工资流水的 `related_no` 由 `EXP2026xxxxx` 改为 `PAY-<工资所属月>-<员工ID>`，
原 EXP 号写进 remark 留痕。**只改字符串，amount 与 balance_after 一律未动，余额链不受影响。**
