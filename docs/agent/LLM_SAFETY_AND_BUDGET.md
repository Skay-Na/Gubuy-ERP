# LLM 安全、预算和审计

## 输入与输出

Planner Provider 复用当前已激活 AI Provider 及既有密钥解密路径。模型只返回 JSON 动作，服务端严格反序列化、拒绝未知字段、尾随数据、超长内容、无效决策和未注册工具。模型不能声明或提升权限。

用户目标与 ERP 文本字段视为不可信内容。工具返回的数据先由服务端限定行数和结果字节数，再作为证据传回模型。Prompt Injection 测试验证注入文本不会变成执行指令；最终权限仍由服务端任务能力和 RuntimeExecutor 校验。

## 预算

默认限制：每任务 8 次 Planner 调用、12 次工具调用、4 分钟运行、16,000 Token、单次结果 6 KiB、Planner 上下文 24 KiB、答案 3,000 Unicode 字符。每个工具有执行超时。超限会保留已有证据并标记部分完成，不再执行模型建议。

Provider 提供 Token 用量时保存 Provider、Model、输入/输出 Token 和耗时；否则按受限请求字节估算 Token 并标记 `token_usage_known=false`。没有可靠的可配置价格表，费用保持未知。不会存储 API Key、完整系统提示或隐藏推理。

## 错误和降级

Provider 不可用、限流、超时、取消、无效 JSON 与参数错误分别分类并持久化。只对可修复的结构化输出错误进行有限重试。普通分析不会用模板伪造成功；确定性监测和库存规则扫描可独立继续，并会向用户说明 LLM 部分未完成。

## 验证边界

运行过 Mock Provider 的正常协议、动态分支、未注册工具/非法参数拒绝、恶意工具输出、调用上限和故障恢复测试。未配置真实外部 Provider，因此真实模型兼容、供应商限流行为、供应商返回的 Token 统计均未在本环境验证。
