# Agent 能力现状

## 当前可用

- 管理员可使用 AI 店长进行多轮查询和业务办理；订单/支出先生成可核对草稿，确认后复用现有业务写入路径。
- Agent 可按用户明确的问题读取商品库存数量；库存摘要不包含低库存数量或缺货阈值。
- 页面记账和 Agent 支出确认使用相同的 `postBookkeepingEntry` 写入函数，统一账户锁、余额、关联订单和财务流水处理。

## 已停用

- 低库存/潜在缺货识别、主动提醒、每日库存扫描、结构化缺货目标、补货草案和长期库存检查计划已从页面、HTTP 路由、Agent 可用工具及应用启动流程停用。
- 历史信号、任务、计划和草案表及记录保留，避免破坏备份和历史数据；后台 Worker 会跳过旧的库存监测任务，不会重放这些记录。
- 正常库存查询与开单库存校验继续工作。Agent 不主动推断补货、囤货或缺货需求。
