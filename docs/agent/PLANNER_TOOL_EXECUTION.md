# Planner 工具执行与权限

## 当前可用工具

只读分析任务按权限获取受限工具目录。当前商品与经营查询包含：

- `retail.product_inventory`：按商品名称读取门店、云仓可售库存。
- `retail.sales_summary`：读取选定日期内有效订单的商品销量与订单数。
- `retail.sales_trend`：比较两个相邻、等长期间的商品销量。
- `retail.inventory_sales`：按用户请求组合当前库存与选定日期内的销量。
- `agent.get_task_status`：读取当前任务状态。

库存查询只返回用户所问的实际数量；Planner 不提供库存扫描、缺货风险提醒、补货草案或长期库存检查工具。旧系统监测/计划任务由 Worker 跳过。

## 执行边界

用户目标、商品名称与备注、数据库内容和工具输出都作为不可信数据传入。Planner 只能从当前任务目录中选择工具，执行层再检查参数、权限和任务范围。工具不直接写库存、订单或资金。

订单和支出由既有 Agent 流程先生成可核对草稿。业务写入需用户明确确认，并复用对应的订单/记账服务。

## 审计与数据保留

当前任务步骤与工具调用仍保存执行状态和受限输入摘要。历史监测信号、任务、计划和补货草案表为备份兼容继续保留，但不再由 Planner/Worker 读取、展示或继续执行。
