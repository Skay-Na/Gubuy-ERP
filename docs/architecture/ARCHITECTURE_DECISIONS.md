# 架构决策

- **AD-1 单体演进**：保留 Vue/Gin/GORM/MySQL，不引入消息中间件或多 Agent 框架。
- **AD-2 数据库为任务事实源**：会话和运行日志只作交互/诊断，不是长期工作流状态。
- **AD-3 规则先行**：监测由确定性查询产生信号；只在需要解释时调用 LLM，且信号结果须有证据与口径。
- **AD-4 默认拒绝写入**：目标和自然语言不构成授权。采购草案、订单提交、对外发送、付款是独立动作。
- **AD-5 单店约束**：现有业务数据没有租户键，因此目前只支持单店数据库。新增模块不能虚构全系统租户隔离。
- **AD-6 兼容迁移**：新增表采用现有 AutoMigrate 机制的加法迁移；生产操作先备份并在隔离库验证。
- **AD-7 明确完成度**：未实现的供应商/采购订单/业务服务共用与端到端验证在报告中保持未完成状态。
